- 日期：2026-11-02
- 范围：BrowserRuntime 兜底异常、配置校验错误
- 结论：**PASS**
- 发布状态：**未发布，npm/GitHub 仍阻塞**

## 一、BrowserRuntime 兜底异常

原来直接抛中文：

- `输入助手请求失败`
- `输入助手已卸载`
- `连接已断开，请重连后保存`
- `连接已变化，请重新加载设置`

现在走 `resolveUiLocale` + `t()`：

- `error.requestFailed`
- `error.disposed`
- `error.disconnectedSave`
- `error.connectionChanged`

`BrowserRuntime` 会记住最近一次保存成功的 `language`；没有保存记录时跟随 DSH locale。

测试：

- `tests/browser-runtime-i18n.test.ts`：断开连接时英文提示。

## 二、配置校验错误码化

`AssistantError` 增加可选 `params`。

`resolveConfig` 抛出具体 code：

- `CONFIG_BOOLEAN`
- `CONFIG_DISPLAY_MODE`
- `CONFIG_SUGGESTION_LENGTH`
- `CONFIG_LANGUAGE`
- `CONFIG_STRENGTH`
- `CONFIG_NUMBER`（field/min/max）
- `CONFIG_STRING`（field/limit）
- `CONFIG_TEMPERATURE`
- `CONFIG_MODEL_PAIR`
- `CONFIG_UNKNOWN`

新增 `src/browser/error-copy.ts`：

- 把配置 code + params 映射到 `config.*` 文案。
- 把运行时 RPC code 映射到 `error.*`。
- 字段名用用户可读标签（上下文上限、建议超时、温度等），不再露出 `debounceMs` 等实现词。
- 未知错误返回 null，由调用方给通用文案，不再拼接中文原文。

设置页和齿轮弹窗：

- 配置错误：`errorCopy` 或 `settings.invalidGeneric`
- 保存错误：`errorCopy` 或 `settings.saveFailedGeneric`
- 删除了会拼接原始 message 的 `settings.invalid` / `settings.saveFailed`
