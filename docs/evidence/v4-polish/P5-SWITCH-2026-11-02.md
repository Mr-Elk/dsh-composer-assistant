# P5 视觉修正：开关形状

- 日期：2026-11-02
- 问题：开关看起来偏方，圆点不像正圆。
- 结论：**PASS**

## 改动

- 轨道：44 × 24。
- 圆点：20 × 20。
- 不再用 `<input>` 的伪元素画开关。
- 改成真实 SVG：
  - `<rect width="44" height="24" rx="12" ry="12">`
  - `<circle cx="12" cy="12" r="10">`
- 隐藏的原生 checkbox 覆盖在上层，仍保留键盘、读屏和测试定位。
- 选中时圆点 `translateX(20px)`。

这样轨道和圆点都由 SVG 几何决定，不依赖浏览器对 input 伪元素圆角的渲染。
