## 这版做了什么

1. **设置页不再重复“输入助手”大标题。** 左侧导航已经写了“输入助手”，DSH 原生设置页也不在内容区放大标题，直接从说明文字开始。
2. **设置页的示例值改成默认值。** 标准长度、15 秒超时、温度 0.7；之前的设计图用的是本机配置（长、20 秒），容易让人误以为默认值就是那样。
3. **弹窗里新增“快捷设置”一层，默认收起。** 收起时只占一行，显示“标准 · 自动”；展开后放三项最常改的偏好，动作仍然排在下面。
4. **快捷设置只放三项：** 建议长度、触发方式、提示词优化开关。三个功能开关仍留在设置页，避免弹窗变成第二个设置页。
5. **输入框入口画成两段。** “✦ 优化”和“⌄”是两个按钮，不是一个胶囊；和现在的实现一致。
6. **候选卡和提示气泡单独出图。** 候选卡保留“换一条 / 采纳 / ×”，气泡区分信息 6 秒、错误 10 秒。

## 和当前实现的差别

- **快捷设置是新设计，代码里还没有。** 当前弹窗只有动作；这组图建议在弹窗顶部加一层可收起的快捷设置。
- **设置页结构没变。** 仍是功能 / 建议 / 优化 / 辅助模型 / 高级五组，13 行；这里只改了标题、示例值和排版。
  保存条画的是可编辑状态；默认没有改动时“保存设置”和“放弃修改”是禁用态。
- **菜单补了信息。** 增加了“快捷设置”摘要、“本次使用统计”的展示/采纳数字、“更多设置”入口；当前实现的统计是折叠的纯文字行。
- **草稿暂存已移除。** 0.2.0 起菜单不再有草稿区，这组图按移除后的界面画；设置里也没有“草稿暂存”开关。
- **深色强调色按真实截图取。** 之前的设计图用 `#4c88e4` 画开关，和真实界面的 `#7aaaff` 不一致。

## 重新生成

```shell
# 首次需要 Chromium；本机已有 Google Chrome 时脚本会自动回退
pnpm exec playwright install chromium
node scripts/render-mockups.mjs
```

脚本会把 10 张 PNG 写到本目录；图片是 2 倍像素，方便放大看细节。
