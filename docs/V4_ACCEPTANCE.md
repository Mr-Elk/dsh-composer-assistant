# 输入助手 v4 阶段验收规范

日期：2026-11-02
适用范围：阶段 0–8
原则：**每阶段先列验收证据清单；完成后再填结果。未达标不进入下一阶段。**

## 0. 通用规则

### 证据位置

每阶段一份：

```
docs/evidence/v4/stage-<N>-<YYYY-MM-DD>.md
```

### 证据必须包含

1. 阶段目标与范围。
2. 改动文件清单（`git status` / `git diff --stat`）。
3. 实际运行的命令与结果（原样粘贴关键输出）。
4. 测试数量与通过情况。
5. 截图路径（浅色/深色/窄窗/状态），图片需要真实生成。
6. 未覆盖项与原因。
7. 结论：PASS / FAIL / BLOCKED。
8. 下一阶段准入判断。

### 判定

- **PASS**：本阶段全部必查项通过，证据齐全。
- **FAIL**：有必查项失败，或证据缺失。
- **BLOCKED**：外部条件缺失（账号、宿主、网络），不是代码问题；记录具体条件和已尝试动作。

### 禁止

- 不把“看起来能用”当证据。
- 不把模拟数据、旧截图、旧构建当本阶段证据。
- 不在 FAIL/BLOCKED 时进入下一阶段。

## 1. 阶段 0：设计定稿

### 必查

- [ ] v4 设计图完整：设置页、设置页悬浮、高级展开、辅助模型下拉、关于弹窗、弹窗、标题 i、情境操作、操作去向表、首次提示、输入框。
- [ ] 四项最终决定都写进图和文档：删触发方式、关于移出表单、高级默认收起、语言跟随 DSH。
- [ ] 操作去向明确：保护、查看/撤销/复制、换一条、暂停、统计/版本/更新。
- [ ] 辅助模型：一个下拉、列表来自 DSH、不手填 provider/model。
- [ ] `DESIGN.md`、`V4_PLAN.md`、`V4_ACCEPTANCE.md`、v4 README 互相链接。
- [ ] 没有未决的结构问题；剩余都是实现细节。

### 证据

- 图文件清单与尺寸。
- 文档链接。
- 结论。

## 2. 阶段 1：基础改造

### 必查

**配置**

- [ ] `nextTrigger` 从类型、默认值、schema、校验、UI、controller 中删除。
- [ ] 旧记录里的 `nextTrigger` 被忽略，不导致加载失败。
- [ ] 手动预测分支删除；永远自动预测；`换一条` 仍可对已有建议生效。
- [ ] 新增 `language`：`follow` / `zh` / `en`，默认 `follow`；旧记录缺失时回落 `follow`。
- [ ] `language` 有范围校验和至少一条测试。

**i18n**

- [ ] 新增统一字典与 `t()`；`follow` 能解析 DSH locale，拿不到时回落 `zh`。
- [ ] 建立字典与 resolver，并为 v4 新增文案（设置页、弹窗、首次提示、关于）列 key。
  旧界面字符串在阶段 2/3 替换时迁移；本阶段以 key 完整性与 resolver 测试为准。
- [ ] key 完整性测试：zh/en 缺 key 会失败。
- [ ] 错误消息映射在阶段 2/3 随文案迁移；本阶段只要求 `t()` 与 key 完整性。

**模型列表**

- [ ] 只读接口/spike 报告：说明数据来源、返回结构、失败方式。
- [ ] 浏览器 runtime 可通过只读接口获取模型列表与失败分组。
- [ ] 接口对空列表/失败返回可判定的 shape；UI 回落与已选模型移除在阶段 2 验收。
- [ ] 不提供手动输入 provider/model。
- [ ] 至少有成功/失败 shape 的测试或 fixture。

**设置草稿**

- [ ] 一个 draft：校验全部字段，和 accepted 做 diff，只提交改动字段。
- [ ] 隐藏字段（语言、高级项）不会被弹窗保存清空。
- [ ] helper 支持同一份 draft；页面/弹窗冲突处理在阶段 2/3 验收。
- [ ] 有单测覆盖 diff、隐藏字段、冲突。

**通用**

- [ ] `pnpm typecheck` 通过。
- [ ] 全量单测通过（Edge 主题可排除）。
- [ ] 没有 UI 回归；旧界面仍能启动（允许暂时保留旧布局）。

### 证据

- 配置迁移测试输出。
- i18n key 完整性测试输出。
- 模型列表 spike/接口样例与失败测试。
- 设置草稿 diff/冲突测试。
- typecheck/测试计数。

## 3. 阶段 2：设置页

### 必查

- [ ] 布局：通用 / 功能 / 建议 / 优化 / 辅助模型 / 高级（默认收起）/ 恢复默认 + 保存 / 关于链接。
- [ ] 功能三个开关；建议只保留建议长度；优化强度；辅助模型下拉。
- [ ] 语言：跟随 DSH / 中文 / English；默认跟随；保存后切换。
- [ ] 高级默认收起；展开/收起不写设置；展开后 5 项完整。
- [ ] 圆圈 i：悬浮、键盘聚焦、触屏点按；空间不足翻转；不挡控件。
- [ ] 条件置灰：提示词优化关 → 优化强度灰；两个建议都关 → 建议长度灰。
- [ ] 关于：表单外链接；独立弹窗；版本/插件页更新说明/复制命令；Esc 关闭、焦点回入口；不参与保存。
- [ ] 保存状态：加载、断线、保存中、成功、失败、未保存、放弃。
- [ ] 辅助模型：列表来自 DSH；失败/移除回落提示；i 显示当前模型、来源、计费。
- [ ] 浅色/深色/窄窗截图；无横向滚动。200% 缩放放到阶段 6。
- [ ] 组件测试覆盖关键交互。

### 证据

- 截图清单（浅/深/窄/高级展开/关于/错误态）。
- 交互测试输出。
- 条件置灰、语言切换、模型回落的测试。

## 4. 阶段 3：输入框与齿轮弹窗

### 必查

- [ ] 星形 16px、齿轮 15px、2px 间距 + 细分隔线；无 `⌄`。
- [ ] 齿轮弹窗只有三项设置（回复后预测、输入续写、建议长度）+ 取消/保存。
- [ ] 标题旁 i：悬浮显示完整设置路径。
- [ ] 保存写整份草稿 diff；没有改动置灰；保存后关闭；取消/点外面丢弃。
- [ ] 弹窗与设置页共用存储；冲突处理。
- [ ] 旧动作菜单删除；controller 动作方法保留给情境 UI。
- [ ] 浅/深/窄/禁用/保存中截图。
- [ ] 组件/浏览器测试覆盖。

## 5. 阶段 4：情境操作

### 必查

- [ ] 选中文字浮出「保护」；点击锁定；不抢选区；无选区不出现。
- [ ] 优化完成后结果条出现：查看改动 / 撤销 / 复制原文；无改动不出现。
- [ ] 撤销恢复原文；编辑后结果条按现有逻辑失效。
- [ ] 候选卡：换一条 / 采纳 / ×；灰字 `Esc` 忽略建议；无建议不处理 Esc。
- [ ] 「暂停至下次编辑」入口删除；`×`/Esc 覆盖。
- [ ] 无手动预测设置后，自动预测正常；换一条仍可用。
- [ ] 真实浏览器测试：选中、保护、查看、撤销、候选卡、Esc。
- [ ] 浮层在窄窗/滚动/贴边时不越界。

## 6. 阶段 5：首次提示

### 必查

- [ ] 第一次打开输入框出现一次；localStorage 记住。
- [ ] 关闭：知道了 / Esc / 点外面；关闭后不重复。
- [ ] 不挡输入、不抢焦点；箭头指向优化+齿轮。
- [ ] 浅/深/窄截图；i18n。
- [ ] 测试：第一次/第二次/关闭。

## 7. 阶段 6：状态与适配

### 必查

- [ ] hover / focus-visible / disabled / loading / error 全覆盖。
- [ ] 深色条件状态：弹窗、i 提示、结果条、选中 chip、关于弹窗。
- [ ] 窄窗 720 / 200% 缩放无横向滚动，工具条不挤压。
- [ ] 键盘顺序、Esc、焦点返回。
- [ ] 截图归档 `docs/design/`；浅/深各一套。

## 8. 阶段 7：测试与验收

### 必查

- [ ] 单测、组件测试、浏览器夹具全部通过；记录数量。
- [ ] Chrome 冒烟通过，0 次付费调用。
- [ ] Windows Edge 主题测试通过（CI）。
- [ ] 宿主 Gateway/包加载/存储迁移测试通过。
- [ ] 真实 DSH `0.2.1-rc.5` 隔离实例人工清单通过：设置保存/重启、语言、辅助模型、Tab/撤销、菜单、失败保留、`/` `@`。
- [ ] 中文 IME 真机确认（或明确记录未验证）。
- [ ] `pnpm pack`、`test:package`、`publish:check` 通过。
- [ ] 发布门禁旧 `lib/` 问题已修：旧构建不能通过。
- [ ] 截图/证据归档。

## 9. 阶段 8：发布

### 必查

- [ ] 版本号定案（建议 0.3.0）；`package.json`、`version.ts`、CHANGELOG 一致。
- [ ] README、SETTINGS、DESIGN、V4_PLAN、验收记录更新。
- [ ] `dist/` 旧包清理；只保留正式 tarball。
- [ ] `pnpm pack:release` 或等价流程通过；包内文件清单正确。
- [ ] GitHub origin、main、tag `v0.3.0`、Windows CI、NPM_TOKEN。
- [ ] npm 发布验证过的 tarball；npm 页面可见。
- [ ] desktop profile 从 npm 安装并重启验证。
- [ ] 回滚方式写进 README。
- [ ] 发布后冒烟与已知限制记录。

### 证据

- 发布命令与输出。
- npm 页面/版本截图。
- profile 安装命令与启动结果。
- tag/CI 链接。
