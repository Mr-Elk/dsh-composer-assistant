# 输入助手 · 产品与视觉设计

目标：让插件看起来是 DSH 自带的一部分，而不是“第三方嵌进来的一块”。
本文覆盖设置页、动作菜单、输入框入口、灰字与候选卡；实现顺序见最后一节。

## 1. 现状诊断（实测对比）

用无头 Chromium 在真实设置弹窗里取的计算样式（DSH 0.2.1-rc.5）：

| 项 | DSH 原生设置 | 当前插件 | 差距 |
| --- | --- | --- | --- |
| 行高 | **75px**（上下各 16px 内边距） | 60px（10px 上下 + 12px 左右） | 行太挤、左右有内缩 |
| 分组容器 | **无边框、无圆角、无底色** | 1px 边框 + 12px 圆角卡片 | 卡片套卡片，视觉噪音最大来源 |
| 分区标题 | 14px / 400 / 主文本色 | 12px / 600 / 次级灰 | 过小、过灰，像表单标签而非分组 |
| 行标题 | 14px / 400 / 主文本色 | 13px / 500 | 偏小、偏重 |
| 行说明 | 13px / 次级 | 12px | 偏小 |
| 下拉控件 | 28px 高 / 8px 圆角 / 13px / 500 / 次级色 | 26px 高 / 13px / 主文本色 | 偏小、颜色过重 |
| 开关 | 36×20，轨道 2px 内缩 | 32×18 | 偏小 |

![原生设置参考](design/reference-native-general.png)

![当前设置](design/current-settings.png)

结论：不是配色问题，是**层级语言不统一**——原生用“字号 + 字重 + 留白 + 细分隔线”，
我们用“框 + 底色 + 小字”。所以越改颜色越别扭。

## 2. 设计原则

1. **借壳，不造第二套控件**：优先复用 DSH 的排版节奏与控件尺寸；插件只带自己的内容。
2. **层级只靠四样东西**：字号、字重、留白、1px 细线。不用嵌套卡片、不用色块分区。
3. **配置与动作分离**：设置页只放“要不要 / 偏好”，菜单只放动作。
4. **默认可直接使用**：所有实现参数留在代码里；用户能判断的才露出。
5. **一眼可恢复**：任何自动改动都能看见、能撤销；提示 6/10 秒自散，不挡输入。

### 明确不做

- 不做自定义字体、字号阶梯（跟随 `--dsw-*` 令牌）
- 不给分组加边框/底色/圆角卡片
- 不用 emoji、不给标题上色
- 不把技术参数（防抖、超时、字符上限）暴露给用户

## 3. 设计令牌

| 类别 | 取值 |
| --- | --- |
| 字号/行高 | 标题 14/22；正文 14/22；说明 13/20；控件 13/20；键帽 10/14 |
| 字重 | 行标题 400；分区标题 500；控件 500 |
| 颜色 | 主文本 `--dsw-alias-label-primary`；说明/控件 `--dsw-alias-label-secondary`；弱提示 `--dsw-alias-label-tertiary`；线 `--dsw-alias-border-l2`；强调 `--dsw-alias-state-business-primary` |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32；行上下 16；分区标题上 24 |
| 圆角 | 控件 8；菜单 12；提示 10；开关 999 |
| 高度 | 控件 28；按钮 28（主要 30）；开关 36×20 |
| 动效 | hover 120ms；开关 150ms；不做出场动画 |

## 4. 组件规格

### 设置行（SettingsRow）

```
┌ 主文本 14/400 ─────────────────────────── 控件 ┐
│ 说明 13/400 次级（可选，与主文本间距 2px）        │
└────────────── 1px 分隔线（最后一行不画）────────┘
```

- 上下内边距 16px，左右 0（与分区标题、弹窗内容区对齐）
- 无卡片、无圆角、无底色
- 控件右对齐，垂直居中；控件与文本最小间距 16px

### 分区（Section）

- 标题 14px/500 主文本色，上下留白 24/4
- 首个分区无上边距
- 分区之间不再加线，仅靠留白

### 开关

- 36×20，轨道圆角 999，滑块 16px，两侧 2px 内缩
- 开：强调色；关：`--dsw-alias-border-l2`
- 焦点环 2px 强调色，偏移 2px

### 下拉 / 输入

- 28px 高，圆角 8，13px/500
- 默认透明底、次级文字色；hover 出 `--dsw-alias-interactive-bg-hover`
- 下拉箭头 12px，右侧 8px
- 文本输入宽 180；聚焦时 1px 强调色描边 + 2px 外环

### 按钮

- 主要：30px 高，强调底、白字，用于「保存设置」
- 次要：28px 高，透明底、次级文字色，hover 出底色，用于「放弃修改」「检查更新」
- 禁用：透明度 0.4，不改变布局

### 提示气泡

- 13px，圆角 10，阴影 `0 6px 24px #0002`
- 贴在输入框卡片上沿外 8px、右对齐卡片右缘
- 信息 6s / 错误 10s 自动消失；点击、Esc 立即关闭

### 菜单

- 宽 360，圆角 12，内边距 6，阴影 `0 12px 40px #0003`
- 行 32px，圆角 8，hover 底色；分组之间 1px 分隔线 + 8px 外边距
- 标题行 13px/500 + 右侧 12px 次级说明

### 输入框入口

```
[✦ 优化] [⌄]
```

- 两段各自 28px 高、圆角 8、无边框；hover 出底色
- 图标 13px、文字 13px/500、次级文字色
- 与「工作区内修改」「模型选择」同高、同色、同圆角

### 灰字与候选卡

- 灰字：14px，`--dsw-alias-label-tertiary`，行高与编辑器一致；末尾键帽 `Tab`
- 键帽：10px，1px 线、圆角 4、内边距 0 4
- 溢出：不截断，自动改用候选卡（卡内保留「换一条 / 采纳 / 忽略」）

## 6. 状态矩阵

| 状态 | 表现 |
| --- | --- |
| hover | 控件/菜单行淡底色 120ms；文字色不变 |
| focus-visible | 2px 强调色外环，偏移 2px；开关同样 |
| disabled | 透明度 0.4；不改变尺寸与位置 |
| 保存中 | 按钮文案变「保存中…」，表单只读 |
| 保存失败 | 行内 `role=alert`，保留未保存值；不清空表单 |
| 深色 | 只用 `--dsw-*` 令牌，不写死颜色；`body[data-ds-dark-theme]` 下复核对比度 |
| 窄窗（<720） | 控件换行到文本下方，右对齐；不横向滚动 |

## 7. 文案规范

- 动作在前：「保存设置」「换一条建议」「检查更新」
- 说明用陈述句，不用「您可以/请」
- 错误说清楚“发生了什么 + 草稿还在”：「模型输出未正常结束，已保留原稿」
- 不出现实现词：`maxNextChars`、`provider`、`ghost`、`panel`

## 8. 实施顺序

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| P0 | 重写设置行/分区样式：去卡片、16px 行高、14px 标题、细分隔线 | 行高 75±2；无任何内层边框；标题 14px |
| P1 | 设置页按蓝图重排（功能/建议/优化/辅助模型/高级） | 与原生「通用设置」并排截图，节奏一致 |
| P2 | 菜单行高 32、分组细线、按钮层级统一 | 菜单高度 ≤ 360；无重复配置项 |
| P3 | 输入框入口与提示气泡对齐工具条 | 浅/深色截图；与「工作区内修改」同高同色 |
| P4 | 灰字/候选卡复核（14px、键帽、溢出转卡） | 长建议不截断 |

每阶段产出浅色 + 深色截图，并与原生设置截图并排比对。

## 9. 验收清单

- [ ] 设置页没有任何“卡片套卡片”
- [ ] 行标题 14px、说明 13px、分区标题 14px/500
- [ ] 控件统一 28px 高、8px 圆角；开关 36×20
- [ ] 浅色/深色均无写死颜色
- [ ] 菜单只含动作，与设置页无重复
- [ ] 灰字不截断；Tab 可采纳；Esc/点击可关提示
- [ ] 200% 缩放与 720px 宽窗口下不横向滚动
- [ ] 截图归档到 `docs/design/`
