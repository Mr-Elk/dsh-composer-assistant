## 这版改了什么

1. **星形从 13px 改成 16px**，和「优化」文字更成一组。
2. **去掉 `⌄`，换成齿轮**；齿轮离「优化」只有 2px，中间一条 12px 高的细分隔线。
3. **齿轮弹窗只放设置**：回复后预测、输入续写、建议长度、触发方式。
4. **没有 tab，也没有操作页**；设置弹窗里不再出现“保护、查看、换一条、暂停、统计”。
5. **操作改成情境出现**：
   - 选中文字 → 浮出「保护」。
   - 优化完成 → 输入框上方出现「✓ 已优化 / 查看改动 / 撤销」。
   - 建议出现 → 候选卡保留「换一条 / 采纳 / ×」；灰字建议只有 `Tab` 采纳，`Esc` 忽略还没接上（见下面“还没定”）。
   - 使用统计、版本、检查更新 → 放到设置页底部「关于」。
6. **设置页新增语言**：通用 → 语言，中文 / English。
7. **设置页说明收进圆圈 i**；简单项不解释。
8. **首次使用提示**：第一次打开输入框时出现一次，点「知道了」关闭。
9. **保存后关闭弹窗**；没有改动时保存按钮置灰。

## 操作去哪了

| 原来在弹窗里 | 现在放哪 | 为什么 |
| --- | --- | --- |
| 保护选中原文 | 选中文字时浮出「保护」 | 只有选中时才有意义 |
| 查看改动 | 优化完成后输入框上「查看改动」 | 只有优化后才出现 |
| 换一条建议 | 候选卡里的「换一条」 | 有建议时才有意义 |
| 暂停至下次编辑 | 候选卡 `×`；灰字建议需补 `Esc` 或悬浮 `×` | 现在菜单项和 `×` 功能重复，但 `Esc` 还没接；补上后再删 |
| 使用统计 | 设置页底部「关于」 | 低频信息，不占输入框 |
| 关于 / 检查更新 | 设置页底部「关于」 | 低频信息，不占输入框 |

这样齿轮弹窗里全是“长期偏好”，没有一次性操作。

## 保存逻辑

- 弹窗只有四项设置；它们和设置页写同一份设置存储。
- 保存写整份设置草稿：校验全部字段，和上次保存的值做 diff，只提交改动过的字段；语言、高级项这些没显示的字段不会被清空。
- 没有改动时「保存设置」置灰；保存成功后关闭弹窗。
- 取消 / 点外面：丢弃未保存改动。
- 如果设置页和弹窗同时开着，设置页重新获得焦点要刷新，或者提示“设置已在别处修改”。

## 语言设置

- 位置：设置页 → 通用 → 语言；不在弹窗里，也不做小按钮。
- 选项：`中文` / `English`；默认 `中文`。
- 和别的设置一起保存；保存后整份插件界面切换语言。
- 范围：设置页、弹窗、首次提示、提示气泡先做双语；宿主错误消息目前是中文，要单独补翻译表。
- 这版只画中文状态；英文设置页可以确认后补。

## 圆圈 i 怎么用

- 简单项（语言、回复后预测、输入续写、提示词优化）不解释。
- 复杂项在标签右边放圆圈 `i`：建议长度、触发方式、优化强度、辅助模型、上下文上限、
  建议超时、每小时调用上限、温度、额外指令。
- 鼠标悬浮或键盘聚焦时显示说明；触屏点一下显示，再点关闭。
- 说明卡按空间翻转；图里为了看清，弹窗的说明卡画在右侧，设置页的说明卡画在行内空白处。

## 首次使用提示

- 第一次打开输入框时出现一次；点「知道了」、按 Esc 或点外面关闭。
- 文案：预测下一句、接着写、整理表达；点齿轮改设置。
- 高亮 `优化 + 齿轮` 这一组，箭头指向齿轮。
- “已提示过”标记建议存浏览器本地，避免多设备同步；具体存哪还没定。

## 关于“草稿”

旧图里的“按当前草稿与光标位置继续写”“超时不会改动草稿”，指的是**输入框里当前的文字**，
不是已经删掉的“草稿暂存”。新版设置页把这些说明收进圆圈 i，页面本身不再出现“草稿”这个词。
