# P3 验收证据：控制器 i18n 与文案总审

- 日期：2026-11-02
- 阶段：0.3.x 设置页收尾 P3
- 结论：**PASS（带残余，见末尾）**

## 一、控制器提示统一 i18n

改动：

- `InputAssistantController` 增加 locale provider，按 `settings.language` + DSH locale 解析。
- 所有 controller 自有提示改为 `notice.*` / `error.*` key：
  - 保护、清除保护、优化关闭、跨越保护片段、超长、未就绪、无结果、草稿变化、已优化、撤销、编辑框不可用、选区限制。
- 宿主错误按 `AssistantError.code` 映射：
  - `DISABLED`、`SESSION`、`STALE`、`INPUT`、`MODEL`、`OUTPUT`、`EMPTY_OUTPUT`、`TIMEOUT`、`CANCELLED`、`BUSY`、`CONFIG`、`TOO_LONG`、`EMPTY`、`PROTECTION`、`LOCK_SCOPE`、`DISPOSED`。
- 未知错误保留原始 message，不吞错。
- `BrowserRuntime` 的 RPC 错误改为带 code 的 `InputAssistantRequestError`，controller 才能映射。

新增测试：

- 英文界面下 controller 提示为英文。
- 宿主 `MODEL` 错误码映射为英文提示。

## 五、残余

- `BrowserRuntime` 的兜底异常（请求失败、已卸载、连接变化）仍是中文，英文界面可能露出；下一轮补 key。
- 设置页把 `resolveConfig` 原始校验错误拼进 `settings.invalid`，英文界面可能中英混合；需要错误码化。
- 宿主未知错误按约定保留原文。
- 上述 BrowserRuntime 兜底和配置校验中英混合已在 P6 前置错误码化中处理。
