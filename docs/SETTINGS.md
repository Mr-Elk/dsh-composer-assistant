# 设置规格（0.3.0）

本文是设置的**唯一事实来源**：哪些键存在、默认值、范围、作用，以及为什么有些参数不暴露。
新增设置前先读第 4 节的门槛。

## 1. 原则

1. 只暴露用户能判断“调了会怎样”的项；实现参数留默认。
2. 每个设置必须有默认值、范围、越界回退，并且不能因为旧记录让插件不可用。
3. 设置页按“功能 → 建议 → 优化 → 辅助模型 → 高级”排列；高级默认展开但置于最后。
4. 动作（优化、换一条、保护、撤销）不进设置，跟着输入区情境出现。

## 2. 用户可见设置

| 分组 | 标签 | 键 | 类型 | 默认 | 范围 | 作用与影响 |
| --- | --- | --- | --- | --- | --- | --- |
| 通用 | 语言 | `language` | 枚举 | `follow` | follow / zh / en | 跟随 DSH 或固定中文 / English；保存后生效 |
| 功能 | 提示词优化 | `optimizeEnabled` | 布尔 | 开 | — | 关闭后主按钮禁用，菜单里的保护/改动仍可查看 |
| 功能 | 回复后预测 | `nextEnabled` | 布尔 | 开 | — | 每轮结束、空输入框时请求下一句 |
| 功能 | 输入续写 | `completionEnabled` | 布尔 | 开 | — | 草稿停顿后请求后缀 |
| 建议 | 建议长度 | `suggestionLength` | 枚举 | `standard` | short / standard / long | 内部映射：短 60/40、标准 120/80、长 300/200（下一句/续写字符上限） |
| 优化 | 优化强度 | `optimizationStrength` | 枚举 | `standard` | light / standard / deep | 控制改写幅度；三档都禁止新增任务或授权 |
| 辅助模型 | 模型 | `provider` + `model` | 成对字符串 | 空 | ≤200 字 | 界面一个下拉；选具体模型时成对写入，留空跟随输入框 |
| 高级 | 上下文上限 | `maxHistoryChars` | 整数 | 16000 | 1000–64000 字符 | 参与建议的历史字数；越大越完整也越贵 |
| 高级 | 建议超时 | `suggestionTimeoutMs` | 整数（界面按秒） | 15000 | 1000–60000 ms（界面 5–60 秒） | 超时返回空建议，不改草稿 |
| 高级 | 每小时调用上限 | `hourlyCallLimit` | 整数 | 0 | 0–2000 | 全局（不分会话）；0 为不限制；只计自动建议，手动优化与「换一条」不计入 |
| 高级 | 温度 | `temperature` | 数字 | 0.7 | 0–2 | 越低越保守；0.3 / 0.7 / 1.0 为常用档 |
| 高级 | 额外指令 | `extraInstruction` | 字符串 | 空 | ≤500 字 | 追加到系统提示词末尾，三个操作都生效 |

## 3. 内部常量（不暴露）

| 键/常量 | 值 | 位置 | 为什么固定 |
| --- | --- | --- | --- |
| `debounceMs` | 600ms | 续写防抖 | 调小会显著增加调用；调大显得迟钝 |
| `minIntervalMs` | 2000ms | 续写最小间隔 | 同上，防抖的第二道闸 |
| `maxDraftChars` | 8000 | 草稿长度上限 | 极少触发，超长应分段处理 |
| `optimizeTimeoutMs` | 60000 | 优化超时 | 大稿改写需要；调整收益低 |
| `displayMode` | `ghost` | 显示模式 | 已自动：放不下转候选卡，不需要用户理解两套模式 |
| `OPTIMIZE_MAX_GROWTH` | 3× | 改写增长上限 | 保护阈值，关掉会让结果失控 |
| 输出上限 | 8192 / 512 / 384 token | optimize / next / complete | 与字符上限配套，调大只增加成本 |
| 预算窗口 | 1 小时 | `CallBudget` | 与「每小时调用上限」的单位一致 |
| 提示停留 | 信息 6s / 错误 10s | 客户端 | 足够读完，不长期占位 |

## 4. 新增设置的门槛

一个参数只有同时满足以下四条才进设置页：

1. **可解释**：能用一句话说清“调大/调小会发生什么”。
2. **安全**：最坏取值不会破坏草稿、不会无限烧钱。
3. **有默认**：不填时行为明确，且旧记录缺失时自动回落。
4. **可验证**：有范围校验与至少一条测试。

不满足的放到内部常量，并在第 3 节登记。

## 5. 存储与迁移

- 存储域：`input_assistant`，版本 1，设置存在 `global.settings`。
- 读取用**宽松解析**：未知键忽略、非法值逐项回落到默认；`provider`/`model` 作为一组处理，成对保留或成对清空。
- 写入用**严格解析**：未知键直接报错，避免调用方写错键被静默吞掉。
- 被删除的键（如 `maxNextChars`、`nextDelayMs`）从旧记录中读到时直接忽略；下一次保存会重写干净记录。
